# Pre-Pilot Demo Script

Audience: garage door repair owner/operator
Goal: earn permission for shadow-mode pilot data or expert review.

## Opening

Show `docs/market/pre_pilot_evidence_report.md`.

Say:

> We do not have live production proof yet. This is controlled pre-pilot
> evidence. The goal today is to decide whether these scenarios look close
> enough to your real inbound leads to justify a shadow-mode pilot or expert
> review.

## Demo Flow

1. Open `docs/market/demo_replays/pre_pilot_replay_report.md`.
2. Show one routine case where the agent asks qualifying questions.
3. Show one urgent/security case where the agent creates human review instead
   of promising arrival.
4. Show one pricing case where the agent refuses to guarantee an exact price.
5. Show one provider failure case where outbound send is not marked confirmed.
6. Show `docs/market/demo_replays/baseline_comparison_report.md`.
7. Show `docs/market/demo_replays/failure_mode_replay_report.md`.
8. Ask the buyer to score 10 cases using `docs/market/expert_review_rubric.md`.

## Ask

Primary ask:

> Can we run a shadow-mode pilot on a small set of inbound leads with every
> outbound message requiring human approval?

Fallback ask:

> If live leads are too early, can you review 30 controlled examples and mark
> would send, needs edit, escalate, or unsafe/wrong?

## Boundaries

- No automated outreach.
- No autonomous-send customer-facing sends.
- No production ROI claim.
- No conversion lift claim.
- No claim that live-client proof exists.
- No paid production readiness claim.
- No payment claim before buyer accepts pilot success and stop criteria.
